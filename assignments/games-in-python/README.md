
# 📘 Assignment: Games in Python

## 🎯 Objective

Create a simple Python game that uses loops, conditionals, and user input to make an interactive experience for players while practicing core programming concepts.

## 📝 Tasks

### 🛠️ Build a Word Guessing Game

#### Description
Create a game where the player tries to guess a hidden word one letter at a time. The game should track progress, limit wrong guesses, and announce whether the player wins or loses.

#### Requirements
Completed program should:

- Choose a word from a predefined list of words
- Show the hidden word as underscores, such as `_ _ _ _ _`
- Ask the player to enter one letter at a time
- Reveal correctly guessed letters in the correct positions
- Track the number of incorrect guesses remaining
- End the game when the player guesses the word or runs out of attempts
- Display a clear win or loss message at the end

### 🛠️ Improve the Game Experience

#### Description
Add a few user-friendly features to make the game more polished and easier to play.

#### Requirements
Completed program should:

- Prevent duplicate guesses from being counted twice
- Inform the player when a letter has already been guessed
- Display the letters the player has already used
- Include a simple difficulty option or a larger word list if desired
- Keep the game loop running until the player chooses to quit
